# Concept Copy Frameworks — the 8 Evergreen Static Ad Concepts

This file defines, for each of the 8 concepts, the **on-image text fields** (what goes inside the Canva template) and how to vary them. The Meta ad-unit fields (Primary text, Headline, Description, CTA button) are the same shape for every concept and are defined once at the bottom.

**Golden rule (from the product):** the creative and the Meta copy must *complement*, not duplicate. Creative = attention + the core idea. Meta copy = depth + persuasion + qualification. Never repeat the on-image headline word-for-word in the primary text — go deeper.

In Step 2 the user picks a concept and says **how many of each element** they want. Generate that many options per element as a numbered menu they mix and match into the template — change the angle, hook framing, and proof across options; keep the concept's core logic intact. Never leave `[brackets]` unfilled. Use the brand's real Voice-of-Customer language from the Executive Summary, not generic marketing speak.

The per-concept fields below are the **element list to ask quantities for** (plus the shared Meta ad-unit elements). Suggested defaults if the user says "defaults": Headlines 10, Subheadlines 6, CTA options 6, Primary text 3, Meta headlines 6, Descriptions 6, and ~5–8 of any concept-specific element (labels, proof stats, review lines, bullets, etc.).

---

## 1. Before & After / Transformation  *(default concept)*
Shows current state → desired state. Use when the result is visually or emotionally clear.

**On-image fields:**
- `Before label` — short, the painful current state (e.g. "Restless 3am nights")
- `After label` — short, the desired state (e.g. "Deep, unbroken sleep")
- `Headline` — the transformation promise (≤7 words)
- `Subheadline` — one line of clarification or mechanism
- `Proof stat` *(optional)* — a number that makes the change credible (e.g. "9 in 10 slept through by night 7")
- `CTA` — outcome-based button text

**Variation levers:** swap the dimension of change (time, money, effort, emotion, status); lead with pain vs. lead with outcome; literal before/after vs. metaphorical.

---

## 2. Us vs. Them (Comparison)
Contrast you against the alternative. Use when you have a clear, defensible advantage.

**On-image fields:**
- `Column A header (Them)` — the old way / competitor category (don't name-attack; use category)
- `Them bullets` — 3 short negatives the audience already feels
- `Column B header (Us)` — your product/brand
- `Us bullets` — 3 short wins that directly counter the Them bullets (1:1)
- `Headline` — the framing line ("Why people are switching")
- `Verdict line` *(optional)* — the one-sentence takeaway
- `CTA`

**Variation levers:** compete on a different axis each time (price, speed, ingredients, process, support, philosophy).

---

## 3. Social Proof (Testimonials, Reviews, Ratings)
Let customers sell for you. Use when you have strong, specific feedback.

**On-image fields:**
- `Star rating` — e.g. ★★★★★ (+ count, "4.8 / 2,300 reviews")
- `Quote` — a real, specific customer line (mark `[REAL QUOTE]` if sourced). Specific > glowing.
- `Reviewer name` — first name + initial / handle
- `Headline` — frames the proof ("Don't take our word for it")
- `CTA`

**Variation levers:** rotate which objection the quote dissolves (price, skepticism, effort, fit). One quote per variation.

---

## 4. USP / Core Benefit / Feature-Led
One big claim, one clear promise. Use when positioning is strong and easy to grasp.

**On-image fields:**
- `Big claim headline` — the single differentiator (the boldest true statement you can make)
- `Subheadline` — what it means for the customer
- `3 benefit bullets` — feature → outcome (each ≤5 words)
- `Proof chip` *(optional)* — badge/number/award
- `CTA`

**Variation levers:** lead with the mechanism vs. the outcome vs. the "only one that…" frame.

---

## 5. Lo-Fi Social Proof (UGC, PR, Comments, Screenshots)
Feels native, not polished. Use when authenticity beats perfection.

**On-image fields:**
- `Native caption` — sounds like a real person posting, not a brand (lowercase, casual ok)
- `Screenshot/comment text` — a believable comment, DM, review, or text thread line
- `Handle / name` — @-style handle or first name
- `Light headline` *(optional)* — minimal, or none
- `CTA` — soft

**Variation levers:** format swap — comment thread / text message / app review / PR snippet / DM. Keep it messy and real.

---

## 6. Product Showcase / Collage
Product front and center. Best for launches, bundles, collections.

**On-image fields:**
- `Product name`
- `Variant / item labels` — for each item in the collage (1–4 short labels)
- `Benefit tags` — 2–4 micro-tags ("Vegan", "30-day", "Ships free")
- `Headline` — clarity over cleverness ("Everything in the bundle")
- `CTA`

**Variation levers:** hero single product vs. collection grid vs. "what's inside the box".

---

## 7. Deals / Promotions / FOMO
Drives urgency. Ideal for converting warm audiences.

**On-image fields:**
- `Offer headline` — the deal, stated plainly ("Buy 2, Get 1 Free")
- `Discount value` — big, scannable ("-40%", "Save €30")
- `Urgency line` — the deadline/scarcity ("Ends Sunday", "While stocks last")
- `Code` *(optional)* — promo code
- `CTA` — action-forward ("Shop the sale")

**Variation levers:** % off vs. bundle vs. gift-with-purchase vs. deadline-only. Keep one dominant offer per ad.

---

## 8. Meme / Humor / Trends / Behind-the-Scenes
Attention through relatability. Best for warming audiences and brand memorability.

**On-image fields:**
- `Top text` — meme setup / relatable situation
- `Bottom text` — the punchline / payoff
- `Relatable caption` *(optional)* — ties it back to the product lightly
- `CTA` — soft, low-pressure ("See why people relate")

**Variation levers:** meme format / trend reference / behind-the-scenes / "POV:" framing. Humor must fit the brand voice — never force it.

---

## Meta ad-unit fields (generate for EVERY concept, alongside the on-image fields)

These go next to the image inside Meta — they add the depth the creative can't.

- **Primary text** (100–250 words): hook first line → pain amplification → pivot to solution → credibility signal → 3–5 feature→benefit bullets → objection handling → CTA. Do not restate the on-image headline verbatim.
- **Headline** (≤40 characters): the below-image headline; must work in isolation.
- **Description** (≤90 characters): supporting clarifier.
- **CTA button**: pick one — Learn More / Shop Now / Sign Up / Get Offer / Get Started.

```
### Subheadlines (×N)
1. ...
### [other concept-specific elements ×N — before/after labels, proof stats,
###  review lines, feature→benefit bullets, badges, offer lines, etc.]
### CTA button options (×N)
1. ...

## META AD UNIT (text next to the image)
### Primary text (×N)   [100–250 words; hook-first; don't repeat the on-image headline]
1. ...
### Meta headlines (×N)   [≤40 char]
### Descriptions (×N)   [≤90 char]
```
