# das-ad-copy-generator ✍️

**Ready-to-paste Meta ad copy for the 8 evergreen static ad concepts — in your brand's voice.**

## What it does
Tell it which concept you want and how many of each element (headlines, subheadlines, body text, features/benefits, CTAs), and it returns a full **copy kit** you paste straight into your Canva template. Every line drawn from real customer reviews is flagged `✓VoC` — usually your strongest performers.

The 8 concepts:
1. Before & After / Transformation
2. Us vs. Them (Comparison)
3. Social Proof (Testimonials, Reviews, Ratings)
4. USP / Core Benefit / Feature-Led
5. Lo-Fi Social Proof (UGC, PR, Comments, Screenshots)
6. Product Showcase / Collage
7. Deals / Promotions / FOMO
8. Meme / Humor / Trends / Behind-the-Scenes

For each variation you get **on-image fields** (for the template) + the **Meta ad unit** (primary text, headline, description, CTA).

## How to use
1. Run [das-meta-ads-context](../das-meta-ads-context) first (or this skill will build it inline).
2. Say *"generate before/after copy"* (or any concept) and how many of each element — or just say *"defaults"*.
