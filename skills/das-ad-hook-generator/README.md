# das-ad-hook-generator 🪝

**32 scroll-stopping Meta ad hooks from a single product URL.**

## What it does
The hook is the first line — the one that stops the scroll. This skill reads your product (URL or description) and generates **32 hooks across 4 categories**:

- 🟢 **Product-focused** — product is the hero
- 🔴 **Problem-focused** — lead with the pain
- 🟡 **Benefit-focused** — lead with the outcome
- 🔵 **Solution-focused** — bridge problem to fix

Each hook is labeled by type (Curiosity, Bold Statement, UGC Review, Social Proof, Problem-Agitation, Aspirational…), and the **top 5 are ranked** with a one-line reason each works.

## How to use
Run [das-meta-ads-context](../das-meta-ads-context) first so hooks use your real Voice-of-Customer, then say *"give me ad hooks for [url]"*.
