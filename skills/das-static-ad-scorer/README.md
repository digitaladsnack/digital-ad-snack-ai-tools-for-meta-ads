# das-static-ad-scorer 📊

**Score your finished static ad before you spend a cent.**

## What it does
Upload a static ad image and it grades it against the **8 criteria of a high-converting static ad**:

1. Headline / Hook
2. Subheadline / Re-hook
3. Additional Copy
4. Visuals / Imagery
5. Offer
6. CTA
7. Simplicity — the 5-Second Rule
8. The Scroll Test

You get a total **out of 26**, a clear launch verdict (**13+ = ready to launch, 17+ = strong winner**), the **top 3 improvements** ranked by impact, and one thing the ad already nails.

## How to use
Say *"score my ad"* and attach the image. (Works in any AI that can see images — Claude, ChatGPT, Gemini.) Run [das-meta-ads-context](../das-meta-ads-context) first so the "customer language vs brand language" checks are judged against your real audience.
