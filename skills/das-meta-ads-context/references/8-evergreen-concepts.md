# The 8 Evergreen Static Ad Concepts

Psychological containers you reuse to scale creative output. Each works across industries because it's rooted in human psychology, not trends. One concept → many ads (change the angle, headline, visual, proof).

1. **Before & After / Transformation** — shows current state → desired state. Use when the result is visually or emotionally clear.
2. **Us vs. Them (Comparison)** — contrast you against the alternative/category. Use when you have a clear, defensible advantage.
3. **Social Proof (Testimonials, Reviews, Ratings)** — customers sell for you. Use when you have strong, specific feedback.
4. **USP / Core Benefit / Feature-Led** — one big claim, one clear promise. Use when positioning is strong and easy to grasp.
5. **Lo-Fi Social Proof (UGC, PR, Comments, Screenshots)** — feels native, not polished. Use when authenticity beats perfection.
6. **Product Showcase / Collage** — product front and center. Best for launches, bundles, collections.
7. **Deals / Promotions / FOMO** — drives urgency. Ideal for converting warm audiences.
8. **Meme / Humor / Trends / Behind-the-Scenes** — attention through relatability. Best for warming audiences and brand memorability.
